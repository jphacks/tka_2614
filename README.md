# PairPath

**ふたりの勉強時間で、ロケットを宇宙で出会わせよう。**

**アプリ：[https://duo-pomodoro.web.app/](https://duo-pomodoro.web.app/)**

**デモ動画:[(https://img.youtube.com/vi/ReWOV-kjg6k/hqdefault.jpg)](https://www.youtube.com/watch?v=ReWOV-kjg6k)**

## 製品概要

### 背景(製品開発のきっかけ、課題等）

1人で勉強していると、つい休憩が長くなったり、スマートフォンに気を取られたりして、続けるのが難しくなります。友達と一緒に勉強すれば頑張れますが、住んでいる場所や時間が違うと、同じ場所に集まるのは大変です。ビデオ通話をつなぎっぱなしにする方法もありますが、カメラや音を気にする必要があり、気軽には続けられません。

そこで、**離れていても「一緒に頑張っている」感覚を持てて、ゲームのように楽しく続けられる勉強タイマー**を作りました。

### 製品説明（具体的な製品の説明）

2人で1つの「勉強ルーム」に入り、**2人の勉強時間の合計**で1日の目標を目指す、協力型の勉強タイマーです。

- 1人がルームを作り、6文字のコードか招待URLを相手に送るだけで、すぐに始められます。
- それぞれが自分の端末で「勉強開始」「休憩」「再開」を操作します。休憩は自由なタイミングで取れます。
- 画面の上には、**地球と月を結ぶ航路**のような進捗バーがあります。自分は地球から、相手は月から、勉強した時間に応じてロケットが進みます。2人の合計が目標に届くと、ロケットが宇宙で合流して「ミッション達成」です。
- 相手が今「勉強中」か「休憩中」かが、イラストとともにリアルタイムで分かります。
- 1日の区切りは日本時間の0時です。目標に届かなかった日は、次に開いたときに結果が表示されます。

### 特長

#### 1. 2人の「合計」で目指す協力型の目標

自分が3時間・相手が1時間でも、2人とも2時間ずつでも、合計が目標に届けば達成です。得意な日・忙しい日を、お互いに補い合えます。左右から伸びるロケットの位置で、どちらがどれだけ頑張ったかも一目で分かります。

#### 2. 相手の様子が、リアルタイムで分かる

相手が勉強を始めたり休憩したりすると、その瞬間に自分の画面のイラストと状態が切り替わります。通話をつながなくても、「相手も今頑張っている」ことが伝わり、ほどよい刺激になります。

#### 3. 登録不要、リンク1つで始められる

ユーザー登録やログインは不要です。ルームを作って、コードかURLを送るだけ。一度入ったルームには、同じブラウザなら自動で戻れます。LINEで送られたリンクも、自動でSafari・Chromeで開き直し参加できます。

### 解決出来ること

- 1人では続かない勉強を、**離れた相手と協力するゲーム**に変えて、続けやすくします。
- 「相手も頑張っている」ことが見えるので、通話をつながなくても、適度な緊張感と一体感が生まれます。

### 今後の展望

- **過去の記録（履歴）画面**：日ごとの目標と実績を一覧で振り返れるようにする
- **アカウント連携**：匿名のアカウントを、そのままGoogleアカウントに引き継げるようにし、別の端末からも同じルームに戻れるようにする
- **ルームの退出・自動削除**：2人とも退出したルームや、使われなくなったルームを自動で片付ける
- **不正アクセス対策**：App Checkで、正規のアプリ以外からの大量アクセスを防ぐ
- 3人以上のチーム、相手が勉強を始めたときの通知 など

### 注力したこと（こだわり等）

- **ずれない・消えないタイマー**：1秒ずつ足すのではなく、「勉強を始めた時刻」を記録して、今の時刻との差で計算しています。タブの切り替え、スリープ、再読み込みをしても、時間がずれたり消えたりしません。
- **日付をまたいでも正しく集計**：勉強した区間（開始〜終了）を記録し、表示するときに日本時間の0時で切り分けます。23:30〜0:40の勉強は、前日30分・当日40分として正しく数えます。
- **宇宙のデザイン**：星空や地球・月はCSSだけで描き、手描き風の丸みやステッカー風のボタンで、長時間表示していても楽しく、目にやさしい画面にしました。

### 独自技術

#### ハッカソンで開発した独自機能・技術

- **セッション方式の時間計算と、日本時間での日付の切り分け**（[src/timer.js](src/timer.js)）
  勉強した区間と「今」から、指定した日の勉強時間を計算します。端末の時間帯の設定に関係なく、必ず日本時間の0時で区切ります。
- **競合に強い開始・休憩の処理**（[src/sync.js](src/sync.js)）
  トランザクションで最新の状態を確認してから書き込み、勉強の区間に「ユーザーID＋開始時刻」の名前を付け、セキュリティルールで上書きを禁止することで、同じ区間が二度と記録されないようにしています。
- **出来事だけを送る同期**（[src/main.js](src/main.js)）
  1秒ごとには通信せず、開始・休憩の出来事だけを送ります。秒ごとの表示は、それぞれの端末が相手の開始時刻から計算するため、通信量が少なく済みます。
- **画像・メッセージの差し替えを設定ファイルに集約**（[src/config.js](src/config.js)）
